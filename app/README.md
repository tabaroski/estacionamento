# App (PWA)

Próxima etapa. O app será um PWA em React com a identidade visual da AV
(fundo preto, amarelo e branco), seguindo as telas aprovadas no canvas de design:
login, cadastro, início, sessão aberta, pagamento, Pix, cartão, pago e histórico,
mais o painel do operador.

Ele vai consumir a API de `backend/`.
